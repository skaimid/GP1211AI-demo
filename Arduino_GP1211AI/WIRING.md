## 接线步骤

### 第一步：电源连接（重要！）

1. **确认VFD模块电压**
   - 测量或查阅规格书确认VCC电压
   - 大多数GP1211AI模块需要 **5V**
   - 有些变体需要 **12V**
   - **错误电压会损坏模块！**

2. **连接电源**
   ```
   Arduino 5V  -----> VCC (VFD模块)
   Arduino GND -----> GND (VFD模块)
   ```

3. **启用控制**
   ```
   Arduino A0 (HV_EN) -----> HV_EN
   Arduino A1 (FL_EN) -----> FL_EN
   ```

### 第二步：SPI数据线

Arduino使用硬件SPI，固定引脚：
- Uno/Nano: D11(MOSI), D13(SCK)
- Mega: D50(MOSI), D52(SCK)

```
Arduino D11 (MOSI) -----> SIA (数据)
Arduino D13 (SCK)  -----> CLKA (时钟)
```

### 第三步：控制信号线

```
Arduino D8 -----> CLKG (栅极时钟)
Arduino D7 -----> SIG  (信号控制)
Arduino D6 -----> LAT  (锁存信号)
```

### 第四步：亮度控制

```
Arduino D3 (PWM) -----> BK (亮度控制)
```

### 第五步：按键（可选）

```
Arduino D2 -----> K_U  (增加亮度按键，另一端接GND)
Arduino D4 -----> K_D  (减少亮度按键，另一端接GND)
Arduino D5 -----> K_M  (菜单按键，另一端接GND)
```

**注意**: 按键使用内部上拉，按下时连接到GND

## 测试检查清单

上电前检查：

- [ ] VCC电压正确（5V或12V）
- [ ] GND已连接
- [ ] 所有数据线已连接
- [ ] SPI引脚正确（D11, D13）
- [ ] 控制线已连接（D6, D7, D8）
- [ ] PWM引脚已连接（D3）
- [ ] 按键已连接（如使用）

上电后测试：

1. 上传Arduino代码
2. 打开串口监视器（115200波特率）
3. 应该看到 "GP1211AI VFD Display - Arduino Port"
4. VFD屏幕应该显示logo或亮度值
5. 按K_U/K_D调整亮度，观察屏幕和串口输出

## 常见问题

### Q: 屏幕不亮？
A: 检查：
1. 电源电压是否正确
2. HV_EN和FL_EN引脚是否连接正确
3. VCC和GND是否接反

### Q: 显示混乱或闪烁？
A: 检查：
1. SPI时钟线是否稳定
2. 所有控制信号是否连接
3. 是否有电磁干扰

### Q: 亮度无法调节？
A: 检查：
1. PWM引脚D3是否正确连接
2. 按键接线是否正确
3. 查看`Disp_Brt_Data`变量值

### Q: 编译错误？
A: 检查：
1. 是否安装了TimerOne库
2. 所有.h文件是否在同一目录
3. Arduino IDE版本是否较新

## 电源建议

- VFD模块工作电流较大（约200-500mA）
- 建议使用外部供电，不要完全依赖Arduino的5V引脚
- 如果使用外部电源，确保共地（Arduino GND与电源GND相连）

## 安全提示

⚠️ **高压注意**
- VFD模块工作时会产生高压
- 模块内部有升压电路，触摸需谨慎
- 不要在通电时插拔连接线

⚠️ **电源反接**
- 反接可能立即损坏模块
- 上电前务必检查VCC和GND

⚠️ **电流过载**
- 确保电源能提供足够电流
- 长时间大电流可能导致过热
